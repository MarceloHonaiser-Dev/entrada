# entrada

Repositório público só para pedidos de acesso de parceiros do método Dev.Marcelo.
O comando `/entrar-no-projeto` do MH.dev.Kit abre aqui uma issue com o login do GitHub e um código de uso único recebido do Marcelo.
Issue sem código válido é fechada sem dar acesso. Não escreva nada além do pedido. Nunca coloque senha, token ou dado pessoal aqui.
